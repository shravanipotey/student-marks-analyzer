# Student Marks Analyzer

A Python program that analyzes student marks and assigns grades.

## Features
- Assigns a grade (A+, A, B, C, Fail) to each student
- Calculates the class average
- Finds the highest and lowest scorers

## Technologies
- Python 3
- Dictionaries, functions, loops

## How to run
1. Install Python 3
2. Download marks_analyzer.py
3. Run: python marks_analyzer.py
